SelfChat（大肥鱼 · AI 对话工作台）—— 绿色压缩包版 使用说明
================================================================

一、这是什么
------------
本压缩包是 SelfChat 桌面版的**免安装**分发件，不含任何安装程序（exe 安装包）。
解压后直接双击 SelfChat.exe 即可运行，不需要安装、不需要管理员权限、
不写注册表、不创建快捷方式。

二、怎么用
----------
1. 把整个压缩包解压到一个**固定的目录**，例如：
       D:\SOFT\SelfChat\
   注意：要解压「整个文件夹」，不要把 SelfChat.exe 单独拖出来，
   因为同目录的 resources\ 等文件是运行必需的。

2. 进入解压出来的目录，双击：
       SelfChat.exe

3. 首次启动会稍慢几秒（要初始化本地数据库），之后正常。

三、目录结构
------------
    SelfChat.exe              主程序，双击这个
    resources\app.asar        应用代码（前端页面 + 后端服务）
    resources\app.asar.unpacked\  原生模块（better-sqlite3 等，不要删）
    locales\                  多语言资源
    *.dll / *.pak / *.dat     Electron 运行时，不要删
    使用说明.txt              本文件

四、你的数据存在哪
------------------
数据**不在**这个解压目录里，而是固定存放在：

    %APPDATA%\s-c\

里面有：
    data.sqlite           聊天记录、设置、API Key
    plugins\              插件目录
    plugins_config.json   插件启停与别名

所以：
  * 换一个目录解压新版本，聊天记录照样在（数据跟着用户走，不跟着目录走）；
  * 删除解压目录**不会**删掉你的聊天记录；
  * 想彻底清空数据，手动删掉 %APPDATA%\s-c\ 即可。

五、升级到新版本
----------------
1. 先关闭正在运行的 SelfChat（确认任务管理器里没有 SelfChat.exe）。
2. 把新压缩包解压到**同一个固定目录**，选择「覆盖」全部文件。
3. 重新双击 SelfChat.exe 即可。

因为用户数据在 %APPDATA%\s-c\，覆盖升级不会丢聊天记录。
如果覆盖时提示文件被占用，说明程序还在运行，先彻底退出再试。

六、卸载
--------
本程序是绿色版，没有卸载程序：
1. 直接删除解压目录即可；
2. 如果也想清掉数据，再删 %APPDATA%\s-c\。

七、常见问题
------------
Q: 双击没反应 / 闪一下就没了？
A: 大概率是没解压，直接在压缩包里双击了。请先完整解压到硬盘目录再运行。

Q: 提示缺少 dll 或被杀毒软件拦截？
A: 本程序未做代码签名，部分杀软会误报。请把解压目录加入白名单后重新解压。

Q: 端口 3000 被占用？
A: 程序内置后端监听 127.0.0.1:3000。若该端口已被别的程序占用，
   请先关闭占用者；重复双击不会多开进程（单实例锁会聚焦到已有窗口）。

Q: 想用 EXE 插件（如 AdShield）？
A: 把插件目录放进 %APPDATA%\s-c\plugins\ 下即可，详见 README-adshield.md。

八、开发者：重新打包
--------------------
    npm run electron:build

产物**只有一个**压缩包：
    release\SelfChat-<版本号>-win-x64.zip

不会再生成 Setup.exe 或 Portable.exe。
