# 🌤️ 复合搜索助手 (compound_search)

这是一个基于原 AstrBot Python 插件移植重构的 Node.js 版本插件。它将**精准天气查询**与**SearXNG 联网搜索**完美结合，并针对本地 AI 对话工作台进行了深度优化。

## ✨ 核心特性

### 1. 极速天气播报
- **智能识别**：自动提取对话中的城市名（支持省市区县）、日期（今天/明天/后天）以及意图（下雨/下雪/晴天）。
- **完美排版**：自动拼接温度、天气状态、相对湿度、风向风力，并匹配对应的 Emoji（如 ☀️、🌧️、💨）。
- **秒出结果**：采用**直接拦截机制**，抓到天气数据后直接返回给前端，**完全不消耗大模型的 Token，实现 0 延迟秒出**。

### 2. 联网搜索 (SearXNG)
- 支持通过 `/websearch 关键词` 触发联网搜索。
- 自动将搜索结果整理并注入到系统提示词中，让大模型基于真实的实时网页数据为你解答。

---

## 🚀 使用指南

### 天气查询
直接用自然语言提问即可，支持以下格式：
- `杭州天气怎么样？`
- `明天北京会下雨吗？`
- `苏州今天的气温`

### 联网搜索
必须使用指令触发，并在后面跟上搜索词：
```text
/websearch 今天的科技圈有什么大新闻
```

## ⚙️ 文件结构与配置

该插件依赖本地数据文件进行城市匹配，请确保你的文件夹结构如下：

text

```
server/plugins/compound_search/
├── main.js              # 插件核心逻辑代码
├── city_data_raw.json   # 全国城市数据字典 (必须存在)
└── README.md            # 本文档
```



> **提示**：如果你在本地部署了 SearXNG 并且端口不是默认的 `8080`，或者你想修改天气数据获取的超时时间，可以打开 `main.js` 修改顶部的 `fetchSearxng` 函数中的 `baseUrl`。

## 🛠️ 插件生命周期

- `beforeChat(messages)`：在每次对话前触发。检测到天气意图或 `/websearch` 时执行抓取逻辑，并返回 `{ isDirectReply: true, content: "..." }` 从而直接接管回复。
- 若当前对话未命中任何意图，插件将静默放行，不干扰正常的大模型聊天。
